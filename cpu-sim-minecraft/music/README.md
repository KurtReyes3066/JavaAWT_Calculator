# Background music

The simulator plays these tracks in random order. The music files are **not included**:
copy your own files into this folder with exactly these names.

| Track | Artist | File name |
|---|---|---|
| Sweden | C418 | `sweden.mp3` (or `sweden.ogg`) |
| Mice on Venus | C418 | `mice-on-venus.mp3` (or `mice-on-venus.ogg`) |

- Tracks that are missing are skipped. With no files at all, the page shows a short notice and stays silent.
- Browsers only allow sound after you interact with the page, so the music starts on your first click or key press.
- The note button in the top bar turns the music on and off. The speaker button does the same for the sound effects.
- To add or rename tracks, edit the `TRACKS` list at the top of `js/ui/audio.js`.

The sound effects (pickaxe, block breaking, chest, footsteps) are generated in code and need no files.
